## 👨‍💻 About Me

I'm **Loknath Surabhi** — a Systems Architect and Full-Stack Engineer who builds tools that other engineers rely on every day.

I specialise in three areas:

- **🤖 Autonomous AI Agents** — Orchestrating multi-LLM pipelines (Gemini, Claude, Codex, Ollama) that work together like a real team
- **⚡ Developer Tools** — Terminal multiplexers, PTY engines, IPC bridges, and ergonomic CLI apps with pixel-perfect responsiveness
- **📈 Trading Intelligence** — Production-grade signal engines that turn raw market data into clear, actionable trade recommendations

> *"Zero bloat, zero telemetry, rock-solid architecture."*

### ⚡ Nexus — AI Terminal & Swarm Workspace

> An autonomous AI agent command centre, resilient terminal multiplexer, and API studio for engineers running multi-agent workflows.

| Feature | What it does |
|---|---|
| 🛡️ **Universal Credential Isolation** | Run Gemini, Claude, and Codex in parallel — no token collisions |
| 🗣️ **Inter-Terminal SpeakDock** | Pipe prompts, errors, and buffers directly between terminals |
| ⏱️ **Zero-Drift Stopwatch** | High-precision wall-clock built into the header beside IST time |
| 🪟 **Resilient Multiplexing** | 8-handle drag resizing with dynamic font scaling — no CLI line-wrap bugs |
| ☕ **Sleep Guard** | Keeps your machine awake while autonomous agents run overnight |

### 📈 SmarTrade — Trading Intelligence Platform

> A 16-gate decision engine for NSE & BSE Indian equities that turns raw market data into clear BUY / SELL / WATCH / NO_TRADE signals.

| Feature | What it does |
|---|---|
| 🎯 **16-Gate Safety Chain** | Every trade passes 16 yes/no checks — any failure = skip |
| 🤖 **6 AI Research Agents** | Technical, Fundamental, Sentiment, Bull, Bear, and Decision agents |
| 📡 **14 Data Providers** | Upstox (live), NSE (official), TradingView, Screener.in, and more |
| 🛡️ **Risk Engine** | ATR-based stop-loss, profit targets, and budget affordability guard |
| 📊 **19 Setup Detectors** | ORB, Range Breakout, 52W High, EMA pullback, FRVP, and more |
